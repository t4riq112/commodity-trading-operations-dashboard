# Commodity Trading Operations Dashboard

## Overview

This project simulates a commodity trading operations workflow using Python, SQL, pandas and matplotlib.

The dashboard calculates trade-level and portfolio-level PnL, performs broker reconciliation, identifies quantity breaks and generates exception reports. Trade data is stored in a SQLite database and queried using SQL.

## Technologies Used

* Python
* Pandas
* SQLite
* SQL
* Matplotlib

## Features

* Trade-level PnL calculation
* Portfolio-level PnL analysis
* Product-level performance reporting
* Trade reconciliation against broker records
* Quantity break detection
* Exception report generation
* CSV report exports
* SQL database storage and querying
* Data visualisation
